注意事项：
1.散热风扇最小型号为4007，若出现电容顶风扇，请换用更矮的电容，或3D打印风扇支架边框内嵌进板子；
2.NTC电阻阻值需与R73匹配，NTC100K匹配100K，NTC10K匹配10K电阻；
3.上层USB-A口和系统温度需要自行进入高级设置界面手动校准；
4.XT-60接口后的电容（超过10.5mm）若过高会顶上层板电感，注意所购买电容高度；

5.板上的测试电阻仅供单独测试快充电路使用，焊接后将不受开关控制；

6.下板的两颗备选电容如有需要可焊接，高度限制7mm；

7.背部的RESET和BOOT按钮会有顶面板的情况，使用钳子剪掉部分按钮帽即可；

8.上层USBA插座请购买不带翻边的插座；
