转自原作者启凡科创

此项目始于2021，4年来预估累计获1W+复刻量，成为广大爱好者焊接的好帮手，帮助实现了大量PCB在DIY过程中的轻松焊接。

但项目设计之初，只考虑了大家好不好用、偏不便宜的问题，也完全开源了所有软硬件，随之而来的就是各种小商贩。

一开始我还会抽时间去闲鱼私聊小商贩让其下架 ，后面实在太多也就不管了，三月份看着某平台实在过于泛滥的现状，心想开源环境这么恶劣再不付出一点行动可能只会越来越烂，就开动设计了优化后的2.0版本并加入了激活码机制。有些人说：“小商贩又赚不了几个钱”，“打官司又不麻烦”等慷他人之慨，站着说话不腰疼的话语。激活码设立后，我每天要查阅大量的佐证材料并花时间去生成激活码，这本不是我该增加的工作量，连五一出去玩都还要做这些，一言难尽。

当时听说M大被反编译破解一气之下删库跑路，我心想，我没做固件特殊处理，破解应该很简单，免费提供激活的项目多久会有人破解呢，今天，它来了，就此，此项目固件终，以后仅硬件放这里供爱好者参考，毕竟是硬件开源社区~     

开源项目被逼到加激活码再到跑路，这本不该是开源该有的样子。

在现有开源项目的基础上修改了原理图部分零件， 按需增加了一些外部接口，同时重绘了更大的PCB底座来适应更大的加热板。我用的是300W，如果更换需要调整隔热板的对应孔位。

（更改供电接口不仅能增加整个设备裸露金属的接地保证安全性，同时三孔的电饭煲电源线也更容易在家里找到。）
