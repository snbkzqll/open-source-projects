项目简介
硬件方面：采用AIR32F103CCT6单片机设计的一个彩屏便携式电烙铁。本版本由蓝天不设防重新设计，更换协议芯片替换为CH224K电压诱骗芯片，关键阻容封装替换为0603，三极管由原来的BC817,BC807替换为SS8050，SS8550(SOT23的更大封装)。支持PD、QC电源输入；支持常规18W、12V/1.5A及以上的充电宝供电；烙铁芯使用常规的T12烙铁芯，兼容性强；采用SW200D震动开关，实现休眠检测。

软件方面：

群里固件已经更新到0928版本固件。优化了开机短时间花屏的问题。

 

现已兼容京东方和翰彩屏幕。

休眠模式新增自动挡（只要烙铁保持在静止状态90秒便可以进入休眠，不严格要求烙铁头处于向上状态还是向下状态）。

 

关于新烙铁头的温度剧烈波动问题，需要连续加热一段时间（15-30分钟，300度左右），温度才会趋于稳定。稳定之后温度波动在正负一度。

 

关于运放芯片选型的问题，目前采用的是MCP6001，可以选择OPA336/SGM8251/GS8331或更多类似的轨至轨运放，注意输出引脚，使用不同运放时温度波动情况可能均不一致。
